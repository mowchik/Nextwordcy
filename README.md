# NextWord v2.0 🎮

Game sambung kata multiplayer real-time.
## Cara Jalankan

```bash
npm install
npm start
```

Buka http://localhost:3000

## Fitur Baru v2.0
- 🚫 Huruf X dilarang (dari sisi server & client)
- 🔥 Sistem streak — 3 kata benar berturut-turut = bonus poin!
- ⭐ Sistem poin (kata panjang = poin lebih banyak)
- 📊 Stats pemain (skor, streak badge)
- 🎊 Konfeti saat menang
- 📱 Responsif untuk semua device
- 🔘 Tombol exit di game screen
- 💬 Teks santai & natural (bukan kaku)
- ⏱ Waktu giliran 12 detik (lebih banyak ruang berpikir)
